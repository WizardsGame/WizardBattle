# Класс `WizardPlayer`

`WizardPlayer` — наследник `Wizard`, представляющий мага, которым управляет игрок. Поэтому он получает базовые характеристики и перемещение по клеткам из `Wizard`, а также содержит логику расчёта доступных клеток и маршрута.

## Поля и свойства

```csharp
public static WizardPlayer Instance { get; private set; }
```

`Instance` — ссылка на единственный активный экземпляр игрока-мага. Класс назначает её при входе узла в сцену и сбрасывает при выходе.

Внутри класса также используются два кэша:

- `_reachableCells` — доступные клетки и стоимость перемещения до каждой из них после последнего расчёта.
- `_cameFrom` — предыдущая клетка для каждого шага; используется для восстановления маршрута.

## Методы

- `_Ready()` — регистрирует экземпляр в `Instance`. Если экземпляр уже существует, удаляет дубликат.
- `_ExitTree()` — сбрасывает `Instance`, если из сцены удаляется зарегистрированный экземпляр.
- `CalculateReachableCells(MapData map, List<Wizard> otherWizards)` — вычисляет доступные для перемещения клетки на текущем поле, учитывая характеристики клеток и занятость магами.
- `IsCellReachable(Vector2I targetCell)` — проверяет, доступна ли клетка согласно последнему расчёту; новый расчёт не выполняется.
- `GetPathTo(Vector2I targetCell)` — возвращает маршрут до клетки из результата последнего расчёта. Если цель не была доступна, возвращает пустой список.

Сначала вызывайте `CalculateReachableCells()`, например при выборе мага. Затем результат можно использовать для подсветки клеток и проверки цели, а `GetPathTo()` — для показа или применения маршрута. После изменения позиции или занятости клеток выполните новый расчёт перед использованием кэша.
