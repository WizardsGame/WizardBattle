# Передвижение игрока

`WizardPlayer.CalculateReachableCells()` ищет маршруты от текущей клетки мага по четырём направлениям. Алгоритм учитывает только клетки внутри карты, по которым можно пройти, и пропускает клетки, занятые другими магами. Суммарная стоимость маршрута не должна превышать `speedTile`.

## Как выбирается маршрут

Для каждого найденного пути суммируется `SpeedCost` клеток — это стоимость прохождения. В первую очередь выбирается путь с наименьшей суммарной стоимостью. Если до клетки можно добраться несколькими путями с одинаковой стоимостью, предпочтение отдаётся пути с большей суммой `Weight`.

```csharp
// Сначала сравнивается стоимость перемещения;
// при равной стоимости выбирается больший суммарный Weight.
int costCompare = a.Cost.CompareTo(b.Cost);
if (costCompare != 0) return costCompare;
return weightB.CompareTo(weightA);
```

Таким образом, `SpeedCost` отвечает за цену пути и ограничивается дальностью мага, а `Weight` служит дополнительным критерием выбора среди равноценных по стоимости маршрутов. Стартовая клетка не включается в список достижимых целей.

## Использование результата

```csharp
var reachable = wizard.CalculateReachableCells(map, otherWizards);
bool canMoveThere = wizard.IsCellReachable(targetCell);
List<Vector2I> path = wizard.GetPathTo(targetCell);
```

Расчёт сохраняет стоимость и связи между клетками во внутренних кэшах `WizardPlayer`. `IsCellReachable()` и `GetPathTo()` используют последний расчёт, поэтому при изменении позиции мага или расположения других магов нужно пересчитать область достижимости. Маршрут возвращается от клетки рядом со стартом к цели; стартовая позиция в него не входит.
