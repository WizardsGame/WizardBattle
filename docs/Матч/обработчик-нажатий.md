# Обработчик нажатий в `Match`

Обработчик управляет выбором мага, перемещением по клеткам и просмотром информации о клетке. Поведение левого клика зависит от текущего режима ввода.

## Режимы ввода

```csharp
public enum InputMode
{
	Default,              // Можно выбрать мага
	WizardPlayerSelected, // Маг выбран: можно указать клетку для перемещения
	CastingSpell          // Заклинание выбрано: ожидается выбор цели
}
```

Переходы между режимами выполняются через `ChangeInputMode()`. При выходе из режима выбора мага подсветка снимается, а при переходе в `Default` выбранный маг сбрасывается.

```csharp
ChangeInputMode(InputMode.WizardPlayerSelected); // начать выбор клетки
ChangeInputMode(InputMode.Default);               // отменить или завершить выбор
```

Чтобы начать режим применения заклинания из UI или другой игровой системы, вызывайте `BeginCastingSpell()`. Обработка выбранной цели для этого режима пока не реализована.

## Нажатия мыши

`_UnhandledInput()` преобразует позицию курсора в координаты клетки и передаёт клик соответствующему обработчику. Клики за пределами карты игнорируются.

```csharp
if (mouseButton.ButtonIndex == MouseButton.Left)
	HandleLeftMouseClick(clickedCell);
else if (mouseButton.ButtonIndex == MouseButton.Right)
	HandleRightMouseClick(clickedCell);
```

- **Левый клик в `Default`:** клик по клетке игрока запускает `BeginWizardSelection()`. Показывается диапазон доступного перемещения.
- **Левый клик в `WizardPlayerSelected`:** доступная и незанятая клетка становится целью перемещения. Клик по своей, недоступной или занятой клетке отменяет выбор.
- **Левый клик в `CastingSpell`:** место для будущей обработки цели заклинания.
- **Правый клик:** выводит тип клетки и возвращает ввод в `Default`.

Пока маг выбран, движение курсора показывает маршрут до доступной клетки. Отдельно вызывать расчёт маршрутов для предпросмотра не нужно: диапазон рассчитывается при выборе мага, а `GetPathTo()` используется для получения пути.

## Функции для игрового кода

```csharp
BeginCastingSpell(); // переключиться в ожидание выбора цели заклинания
```

`BeginWizardSelection()` и `UpdatePathPreview()` — внутренние методы `Match`; их напрямую вызывать не требуется. Для отмены выбора используйте `ChangeInputMode(InputMode.Default)` внутри `Match`.
